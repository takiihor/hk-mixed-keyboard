# 粵拼候選讀音開關設計

**日期：** 2026-07-17

## 目標

在設定頁加入「顯示粵拼候選讀音」toggle，讓用戶選擇是否在候選列和展開候選表中看見粵拼讀音及數字聲調。

## 已確認的行為

- 預設為關閉：粵拼候選只顯示漢字。
- 開啟時，粵拼候選顯示「漢字 · 粵拼／數字聲調」。
- 此設定只影響 `SourceSchema.JYUTPING` 的可見標籤；速成、拼音更正及中英提示的標註維持原樣。
- 解碼器仍會產生讀音資料，顯式聲調仍可用於候選排序及消歧，提交結果不變。
- TalkBack 的候選內容描述繼續包含讀音，不受視覺開關影響。

## 設計

在 `KeyboardSettings` 增加持久化布林設定，預設 `false`。設定頁在「輸入設定」中提供對應 switch，開關變更會寫入 DataStore。

IME 既有的設定 flow 把該值傳給候選列和候選表。兩個元件把值傳進 `CandidatePresentation`，僅在候選來源為粵拼且設定關閉時省略可見 annotation。無障礙內容描述仍直接採用候選原有 annotation。

這個分層把「候選資料是否存在」和「是否顯示給熟手粵拼用戶」分開，避免破壞聲調排序與無障礙資訊。

## 驗證

- 單元測試：關閉時隱藏粵拼 annotation；開啟時顯示它；非粵拼 annotation 保留。
- 設定模型測試：新偏好未設定時預設為關閉。
- 執行 Android debug unit test suite 與 debug APK 組建。

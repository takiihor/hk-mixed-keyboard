# Keyboard Row Height Adjustment Design

**Date:** 2026-07-16  
**Status:** Approved

## Goal

Increase only the main keyboard row height from 48dp to 52dp so ordinary typing keys have a modestly larger vertical target.

## Scope

Change \`KeyboardLayout.BASE_ROW_HEIGHT_DP\` from \`48f\` to \`52f\`. This affects every row generated by \`KeyboardLayout.rowsFor()\`, including text, number, signed-decimal, phone, email and URI layouts.

The responsive horizontal grid remains unchanged. Candidate-bar height stays 48dp; symbol-panel geometry, Settings controls, typography, one-handed width and key weights are not redesigned.

## Behavior and safety

Keyboard height is derived from the row-height constant, so the existing measurement path recalculates the total height for every input surface. Existing Android height scaling continues to apply. Accessibility bounds derive from the same cells, so their vertical target grows with the visual key.

## Verification

Update the keyboard-layout contract tests from 48dp to 52dp, verify every surface reports the expected total height, and run focused keyboard tests followed by the Android unit/lint suite. Review emulator rendering to confirm that the increased keyboard remains clear of navigation-bar insets.

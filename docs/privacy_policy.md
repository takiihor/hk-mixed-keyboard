# 隱私政策 / Privacy Policy — HK Mixed Keyboard

更新日期 Last updated: 2026-06-16

HK Mixed Keyboard（下稱「本 App」）是一款離線輸入法（IME）。本 App 不需要網路權限，不會傳送、收集或儲存您的輸入內容至任何遠端伺服器。

HK Mixed Keyboard is an offline input method (IME). The app requires no network permission, and it does not transmit, collect, or store your input to any remote server.

## 權限 Permissions
- 振動 VIBRATE：用於按鍵觸覺回饋（可在設定中關閉）。Used for key haptic feedback (can be disabled in Settings).
- 無 INTERNET 權限。No INTERNET permission.

## 資料處理 Data Handling
- 輸入內容（鍵入的文字）僅在本機即時處理，用於顯示候選字詞與提交輸入，不會被上傳或持久化儲存。
- 個人詞庫（可選功能）僅儲存在您的裝置本地資料庫，用於提升候選排序；您可在設定中一鍵清除。

Input is processed on-device only to produce suggestions and commits. No data leaves your device. Optional personal dictionary is stored locally and can be cleared in-app at any time.

## 第三方服務 Third-Party Services
本 App 不整合任何第三方分析、廣告或雲端輸入服務。
No analytics, ads, or cloud input services are integrated.

## 兒童隱私 Children’s Privacy
本 App 不蒐集個人資訊；若您是家長/監護人並對孩子的裝置使用有疑慮，請與我們聯繫。

## 聯繫 Contact
如有隱私問題或請求，請透過電子郵件與我們聯繫：support@hkmixedkeyboard.example

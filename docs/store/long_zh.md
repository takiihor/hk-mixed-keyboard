主要功能
- 三種直接模式：速成、標準粵拼及面向香港繁體輸出的普通話拼音
- 速成兩碼：首尾兩碼快速輸入常用字
- 粵拼支援可選 1–6 聲調及分隔符，輸入聲調會改善候選排序；拼音支援聲調符號/數字、撇號及連續輸入
- 鍵盤模式鍵：依次切換速成（速）→ 粵拼（粵）→ 拼音（拼）
- 長按模式鍵可直接選擇；設定可調鍵盤高度及單手位置
- 繁體預設：需要時可在設定或長按空白鍵切換簡體輸出
- 完全離線：無網絡候選、無網路權限，輸入不出機
- 觸感優化：短促清晰、不重疊

使用技巧
- 兩碼英（如「ok」「hi」）優先當英文，避免誤送
- 點按 ？！輸入？，長按輸入！
- 空格選安全的精確中文候選；Enter 保留刻意輸入的原文；自動選字後退格可還原組字
- 設定可切：輸入模式、嚴格結果優先的可選模糊拼音、繁／簡、字根、高度、單手、震動/聲音

私隱
- 無網絡權限；分模式自訂詞及學習排序只存本機，可匯出或清除

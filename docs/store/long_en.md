Highlights
- Three direct modes: Quick, standard Jyutping and Hanyu Pinyin for Hong Kong Traditional output
- Quick 2-code: first+last codes for common characters
- Jyutping accepts optional tone digits 1–6 and separators, and tone digits refine ranking; Pinyin accepts tone marks/digits, apostrophes and continuous input
- On-keyboard mode button cycles Quick (速) → Jyutping (粵) → Pinyin (拼)
- Hold the mode button to choose a mode directly; adjust keyboard height or one-handed layout in Settings
- Traditional Chinese by default; switch Simplified output in Settings or by holding Space
- Fully offline: no network candidates or network permission; input stays on device
- Crisp haptics: short, clear, non-overlapping

Tips
- Two-letter English ("ok", "hi") stays English by default
- Tap ?! for ? and hold it for !
- Space selects a safe exact Chinese result; Enter preserves intentional literal input; Backspace restores a just-auto-selected composition
- Settings: input mode, strict-first optional fuzzy Pinyin, Traditional/Simplified output, roots, height, one-handed layout, vibration/sound

Privacy
- No network permission; bounded per-mode custom entries and learned ranking stay local and can be exported or cleared

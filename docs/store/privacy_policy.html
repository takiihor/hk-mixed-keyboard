私隱政策 / Privacy Policy — HK Mixed Keyboard

更新日期 / Last updated: 2026-07-15

摘要 / Summary

HK Mixed Keyboard 是完全離線的 Android 輸入法，沒有網絡權限、廣告、分析、追蹤、雲端輸入或當機回報 SDK。輸入內容、詞庫、設定及統計不會傳送給開發者或第三方。

HK Mixed Keyboard is a fully offline Android input method. It has no internet permission and no advertising, analytics, tracking, cloud-input or crash-reporting SDK. Typed content, dictionaries, settings and statistics are never sent to the developer or a third party.

本機資料 / On-device data

  • 按鍵、目前組字及少量前文只在記憶體中處理，不會保存為逐字輸入紀錄。 Keystrokes, active composition and limited preceding context are processed in memory and are not kept as a typed-text log.
  • 選用候選、輸入碼和手動新增的速成、粵拼或拼音詞條可保存於 App 私有 hk_user_memory.db，只用於本機排序。 Selected candidates/codes and custom entries may be stored in that app-private database for local ranking.
  • 模式、主題、震動、聲音、鍵盤高度、單手模式及簡體輸出等偏好保存在 App 私有 DataStore。 Preferences are stored in app-private DataStore.
  • 資料保留至您刪除個別項目、清除所有個人詞庫、清除 App 資料或解除安裝。 Backup is disabled and there is no server copy.

敏感欄位 / Sensitive fields

密碼、數字密碼，以及付款、銀行、信用卡、安全碼和一次性密碼提示欄位會停用前文、預測、候選歷史及學習。 Password, numeric-password, payment, banking, card-security and one-time-code fields disable context inspection, predictions, candidate history and learning.

匯入、匯出及刪除 / Import, export and deletion

匯出只在您選擇的位置建立自訂詞語 CSV。匯入經 Android 文件選擇器授權，限制檔案大小、行數、行長、詞語及輸入碼，要求有效 UTF-8，並在任何錯誤時取消整批匯入。 Export writes custom entries only where you choose. Import is document-picker scoped, bounded, strict UTF-8 and atomic. Settings can delete individual entries or all learned/custom data after confirmation.

權限及分享 / Permissions and sharing

  • VIBRATE：只用於可選觸覺回饋。 Optional haptic feedback only.
  • 沒有 INTERNET 權限、資料分享、資料銷售、廣告或第三方分析。 No internet permission, data sharing, data sale, ads or third-party analytics.
  • allowBackup=false；個人詞庫不會進入 Android 雲端備份。 Cloud backup is disabled.

兒童私隱 / Children's privacy

本 App 不會在知情下收集任何人的個人資料，包括兒童。 The app does not knowingly collect personal data from anyone, including children.
